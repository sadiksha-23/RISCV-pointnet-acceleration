# Selection patterns

- `shape_experiment.py`: synthetic shapes, N=1,000 M=32. Results: `results/synthetic_1k_32/`.
- `kitti_fps_structure.py`: KITTI exact 3D FPS geometry, N=100,000 M=128. Results: `results/kitti_100k_128/`.
- `run_kitti_experiment1.sh`: KITTI launcher.

These are geometric observations, not speed benchmarks.
